# Dev log – 25 October 2026

Phase 4 (web search tool). Phase 3 is skipped: customer data moved to Bonus 6.1.

Branch: `phase-4/web-search-tool`, created from `main`. It only needs `config` from Phase 0, so it does not depend on PR #1 and PR #2 and can be merged on its own.

## What was built

- `premortem/tools/web_search.py`: `@tool web_search(query)` wrapping `TavilySearch`.
  - Returns at most `MAX_SEARCH_RESULTS` results, each with only `title`, `url`, `snippet` (snippet cut at 500 characters).
  - Errors are returned as data (`[{"error": ...}]`), never raised: missing key, API exception, no results, unexpected response.
  - The docstring is the tool's prompt: when to use it, how to phrase queries (category + country), what it returns.
- `tests/test_web_search.py`: 7 offline tests with a fake client, 1 live test skipped without `TAVILY_API_KEY`.

Done when check: `web_search.invoke({"query": "plant-based snacks market France"})` returns 5 results with URLs.

## Manual test: 3 queries about the demo product (Proteo Crisps, France)

| Query | Result quality |
|---|---|
| `plant-based protein crisps competitors France` | Relevant to the category but **global**: 5 market-report vendors (Persistence, Future Market Insights, Mordor, Grand View...). Competitor names are global brands (General Mills, Optimum Nutrition, Myprotein), no French brands such as Gerblé. |
| `protein snacks market size France` | Partly **off target**: 2 of 5 results are about the France protein *ingredients* market, not protein snacks. The others are global reports with a France paragraph. |
| `French consumer trends protein snacks Nutri-Score` | **Good**: France-specific sources on Nutri-Score adoption (Santé publique France, a PMC paper, NielsenIQ/Kantar coverage). |

Takeaways for the Analyst prompt (Phase 5):
- Ask for **brand-level** queries (e.g. "protein crisps brands France supermarket", "Gerblé protein snacks price") instead of "competitors".
- Market-report pages are paywalled summaries: treat their figures as weak evidence and note them in `data_quality_notes`.
- The document's own figures (NutriMarket Insights, France Snack Panel) should stay the main source for segment sizes.

## Free-tier usage

- Tavily plan: Researcher (free), **1,000 credits per month**. A basic search costs 1 credit.
- Searches per full run: `ANALYST_RECURSION_LIMIT = 15` allows at most about 7 search rounds (each round is one `analyst_llm` step plus one `tools` step, plus the final `analyst_report`). With 1 to 3 parallel calls per round, one run uses about **5 to 20 searches**.
- So the free tier covers roughly 50 to 200 full runs per month. Phase 10 (5 cases, a few runs each) fits, but repeated tuning runs in Phase 5 should be counted. Check usage with `GET https://api.tavily.com/usage`.

# Phase 5 – Analyst subgraph

Branches, stacked on Phase 4: `phase-5/analyst-prompt` (prompts) → `phase-5/analyst-subgraph` (code, tests, runs).

## What was built

- `premortem/prompts/analyst.md`: research phase. Role, procedure (read brief and document first, then search), brand-level queries, about 6 searches, no invented figures, report small segments as they are.
- `premortem/prompts/analyst_report.md`: structuring phase. Source numbering, one document source per section, one competitor per brand, a source id on every need and figure, plus one good competitor and one good segment example (about a different product, so the demo answers do not leak).
- `premortem/agents/analyst.py`:
  - `get_analyst_tools()` returns `[web_search]`: the single place to add bonus tools.
  - `analyst_llm` → `tools` (`ToolNode`) loop, routed with `tools_condition`, capped at `MAX_TOOL_ROUNDS = 6`, derived from `ANALYST_RECURSION_LIMIT`, so the loop ends in a report instead of a `GraphRecursionError`.
  - `analyst_report`: `with_structured_output(Analysis)` on the document plus a plain-text research log (no tool history in the call).
  - `normalize_sources` (code, not LLM): renumbers sources `S1, S2...` (document first, then web), removes web sources whose URL never appeared in a search result, removes citations to unknown ids and sources nobody cites, and records every removal in `data_quality_notes`.
- `tests/test_analyst.py`: 6 offline tests (fake LLM). `tests/run_analyst.py`: live run, saved in `outputs/analyst_runs/`.

## Hand check (competitors, URLs, figures)

- Every figure cited in run 1 (380M euros, +443%, 70–75 euros/kg, 2.20 euros per bar, 43.3 g, 65%) appears in the research log: no invented numbers.
- All cited URLs come from Tavily. 5 open directly; carrefour.fr (403) and barebells.fr, minceurdiscount.com (429) block scripts but are real pages.
- The trap is reported correctly in every run: vegans are 1.3M adults, 2.5% of adults, 72% intent.
- Competitors are real brands (Barebells, Gerblé, private labels, IronMaxx, Minceur Discount...). The analysis also flags that Gerblé and Barebells sell no protein crisps in France: useful for positioning.

Problems found and fixed:
1. Run 1 grouped three brands in one competitor → prompt: one entry per brand.
2. Run 1 put five document sections in one source, plus a duplicate → prompt: one source per section.
3. Some customer needs had no source id → prompt: every need ends with `[Sx]`.
4. Code: ids cited in `data_quality_notes` were not renumbered, and uncited sources were kept → fixed in `normalize_sources`.
5. Code: a real URL was removed because the LLM dropped `www.` → URLs are now compared without scheme, `www.` and trailing slash, and the exact search URL is kept.

## Cost and limits

- One run: about 62–70k tokens (mostly input, because the document is sent in every turn), 7–8 Tavily searches, about 50 seconds.
- The tool-round cap was never reached (max 3 of 6 rounds), so the limit does not need lowering.
- Tavily free tier: 1,000 searches a month, so about 125 full Analyst runs.

Open points after the Phase 5 runs (noticed while preparing Phase 6):
- Run 4 again put several document sections in one source (S1), despite the prompt rule. Haiku does not always follow it; a Phase 7 warning rule could check it.
- IronMaxx is cited with German and Slovenian shop pages (.de, .si), not French ones. The Analyst prompt asks for the target country, but nothing checks it.

# Phase 6 – Strategist and Creative

Branch: `phase-6/strategist-creative`, stacked on `phase-5/analyst-subgraph`.

## What was built

- `premortem/prompts/strategist.md`: STP procedure. Targeting compares size, interest, accessibility, competition and fit with goals, and reads size and interest together. `target_segment_id` and source ids must exist in the analysis. Channels are short names that the campaign reuses. Includes how to use validation issues and human feedback.
- `premortem/prompts/creative.md`: campaign copy in the language of the target country, one message per strategy channel and no other channels, claims only from the brief or the strategy.
- `premortem/agents/revision.py`: shared revision logic. A node revises when the latest validation of its own stage has blocking issues, or (Strategist only) when `human_feedback` is set. The previous output, the issues and the feedback are added to the prompt ("Revise the strategy. ..."), and the revision counter is increased.
- `premortem/agents/strategist.py`, `premortem/agents/creative.py`: nodes with `with_structured_output(Strategy)` / `(Campaign)`. The Strategist sees the brief and the analysis, not the raw document, so every claim goes through the analysis sources. The Creative also gets the target segment.
- `tests/test_strategist_creative.py`: 6 offline tests on the revision logic (fixture `dummy_state.json`). `tests/run_strategist_creative.py`: live chain on a saved Analysis, with an optional `--feedback` rejection. It saves to `outputs/strategy_runs/`.
- `tests/run_analyst.py` now also saves `brief.json`, so later phases do not extract the brief again.

## Marketing check (read as marketers)

Problems found in run 1 and fixed in the prompts:
1. Comparative claim "Plus de protéines que les chips protéinées habituelles": it came from the +30% claim, which the analysis flags as measured in Italy only. Now the Strategist uses only claims not flagged in `data_quality_notes`, and the Creative makes no comparative claims unless the strategy says they are valid in the target country.
2. Tagline "Le croquant qui vous muscle": it promised a body effect and contradicted the concept. Now claims stay factual, and the tagline must express the positioning. Run 2: "Croquant. Protéiné. Tout simplement."
3. Supermarkets and Hypermarkets were separate channels with almost the same message. The prompt now says to merge them. Haiku follows this rule only sometimes (run 3 split them again), so it is a candidate for the Phase 7 judge.

Still to watch:
- The positioning statement sometimes uses internal wording ("the unverified protein chips of IronMaxx"). It is fine for the team but must not reach the copy.
- Flavour names stay in English ("Sea Salt", "Rosemary") inside the French copy. Decide whether they are brand names or should be translated.

## Cost

One Strategist + Creative chain: 2 LLM calls, about 30 to 45 seconds with Haiku. The `--feedback` run adds one Strategist call.
